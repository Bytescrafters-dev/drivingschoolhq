# Responsive UX

Every new dashboard UI should be considered at:

- desktop
- tablet
- small-screen/mobile widths

## Common Risk Areas

Review:

- sidebar behavior
- table overflow
- filter bars
- page-header actions
- form grids
- dialogs
- cards
- breadcrumbs
- action menus

## Tables

For wide tables, use an intentional strategy:

- horizontal overflow
- hide lower-priority columns
- card/list alternative
- responsive column configuration

Do not let content silently overflow the viewport.

## Forms

Avoid fixed widths that break small screens.

Use existing responsive grid/stack patterns from nearby forms.

## Headers and Actions

Allow action groups to wrap or stack where needed.

Do not assume all page titles and buttons fit one row.
